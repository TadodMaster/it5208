# it5208
Thống kê ứng dụng - Bernoulli process

## Requirements

- Definition​
- Differences from the other types of stochastic processes ​
- Example of at least three real-world applications​
- Code implementation (in python - using existing exact functions for the process is prohibited) and demo​

- Notes:​
  - The student group must prepare a zip file named in the following format: <group_name>.zip. The zip file contains slides and code, and must be uploaded to Teams one day before the presentation.​
  - The group registering later must not choose the same topic as the group that registered earlier. Two student groups are not allowed to select the same presentation topic.​

## Project structure

```
it5208/
├── code/
│   ├── bernoulli_process.py   # Bernoulli process from scratch (only random.random())
│   └── demo.py                # simulations, theory checks, figures
├── figures/                   # generated by demo.py (PNG)
└── README.md
```

## How to run the demo

```bash
pip install matplotlib
cd code
python demo.py
```

Prints simulated vs theoretical mean/variance (Binomial, Geometric), the memoryless check and an application example. Figures are saved to `figures/`.
